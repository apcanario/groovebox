### Should-fix

**S1. At 360 x 640 the Advanced lane is still squeezed beside Back and New idea.** `src/ui/tabs/LayerTab.tsx:209-216`, `src/style.css:1795`. The bundle-4 player's finding is only half fixed: on a short screen the lane is 171 of 336 px wide (about 135 px before). Full width needs one 48 px row more, and the Notes page has no slack (lead dials already near their 64 px minimum). Fix: either (a) find the room (for example, below 700 px screen height put Back and New idea on a row with the style chips as a 7-cell grid only if each cell stays at least 48 px, or drop the lane to 40 px and the lead dial rows to 64 px and check with `shots.py`), or (b) if no layout fits, keep it and record under Choices in the changelog: "at 360 x 640 the Advanced Layer lane stays beside Back and New idea (171 px, up from about 135 px); full width from 700 px height", so Pedro can veto. Do not shrink a control under 48 px.

**S2. "No click" is not checked.** `tools/smoke.py:1042` (`walk_p6`). Smoke checks peak and dial reach only. Fix: add a level-continuity check while a long note sounds (Drift, Note length 100, Busy high): sample the layer's output at a short interval (or tap the analyser's time-domain buffer) while each lead dial is turned and the style is switched, and fail on a sample-to-sample jump well above the note's own slope. This is the same "tested by level continuity" check P9 will need, so put it in a helper.

**S3. The stuck-note check cannot see a stuck note.** `tools/smoke.py:1092-1097`. Switching the layer off cuts every voice, so a note that never ends on its own would still pass. Fix: after the dial turns, leave the layer on, set Busy to 0 (`setGen(..., {density: 0})`) and wait for `activeVoices('layer1') === 0` within the longest note plus release (8 bars at the current bpm plus the patch release); then do the off check as now.

### Minor

**M1. "Dip" and "Zig" are acceptable under the text-fit rule; record them.** `src/ui/logic.ts:428`. Measured at 360 x 640: the dial's value box is 25 px; "Valley" needs 27.9 px and "Zigzag" 29.6 px at 10 px, weight 800, so spec 8.6 requires shortening in the source. "Dip" is a fair word for Valley; "Zig" is less clear but readable beside Rise, Fall and Arch. Fix: add both to the changelog's Choices (the screen word differs from spec 8.5's selector names).

**M2. The phrase bar reads as a beat marker.** `src/style.css:1777`. Unlit segments use `--line` and are almost invisible on the lane, so the one lit segment looks like a position in the bar (in the 412 x 915 Simple shot, a white bar under beats 9 to 12 of a 4-bar phrase). Fix: draw unlit segments in `--dim` so the row of N segments is visible, keeping the lit one in `--text`.

**M3. Dead code left by the new layout.** `src/ui/logic.ts:422`: `LEAD_STYLE_ORDER` is exported and never used; remove it. `src/style.css:658`: `.roomy .lanerow .lane` no longer matches anything (the lane row is only drawn on short screens); remove that selector. `src/style.css:1804`: `.layertab.adv.roomy > .lane` repeats `.roomy > .lane` (height 52 px); remove it or keep only the `flex: none` it adds.

**M4. Pulse page at 360 x 640 leaves about 75 px empty** under its three dials. `src/style.css:1812`. Fix: let `.dials.lead.n3` rows grow to fill the page (`grid-auto-rows: minmax(64px, 1fr)` or the page's flex), so the three dials get the room.

**M5. In Pulse on a short screen no chip names the edited section.** `src/ui/tabs/LayerTab.tsx:192`. With five chips the "· B" is dropped and only the strip's Editing mark shows it. Reasonable; fix: record it under Choices in the changelog.

**M6. `tools/shots.py:25` copies the shape list from `src/music/lead.ts`.** It can drift. Fix: read the shapes from the page (export `LEAD_SHAPES` on `window.__groovebox`) or have smoke assert the two lists are equal.

**M7. Unreadable failure message.** `tools/smoke.py:1097` builds `window.__groovebox.activeVoices('layer1')` from `chr()` calls. Fix: read the count into a variable with a plain string and put it in the message.
