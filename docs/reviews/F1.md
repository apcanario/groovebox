## Errors

**E1. `tools/shots.py` is no longer reproducible.** `tools/shots.py:1519` opens the app with no bag seed, so the launch jam is drawn from `Date.now()` and every walk after it (frame, live, tablet) measures a random top vibe. Before F1 it measured the default song. Run 1 drew Drone and failed eight times (S1); run 2 passed. A check that passes or fails by the clock hides regressions and will break the bundle player's run at random. Fix: in `main()`, before `page.goto`, `page.add_init_script(BAG_SEED)` (move `BAG_SEED` to `shots.py` and import it in `smoke.py`, as `walk_picker` already is), then open the default song from Songs as `open_app` does (`window.__keeper.create()`), so the frame walk measures what it measured at c6a7e01.

**S2.
